## Objective
Build **Yakusoku**: a pre-signature firewall for AI agent x402 payments. It only signs payments that match a **user-signed intent** (EIP-712 `TaskIntent`). Pipeline: idempotency → policy → provenance → Intercepta → Jev (TypeSafe) → World ID for Agents → sign.

## Problem and why
AI agents can be tricked by prompt injection into paying a **clean address, within budget, for something never requested**. All existing guards (Privet, x402-Guardrails, intentOS, IntentLayer, smart402, Aegis402...) are deterministic or post-hoc. Yakusoku adds a calibrated semantic intent check **before** signing. Evidence: `../../docs/16-estado-del-arte.md`, `../../docs/22-showcase-validacion.md`, `../../docs/research/spike-jev-resultados.md`.

### Verified gotchas (from the docs pass)
- **x402:** the SDK's $1/payment default cap fails silently → always set `spendControls`. `payment-identifier` lives in `@x402/extensions`. There are **two differently-shaped `encodePaymentSignatureHeader` variants**: use the one in `ref-x402.md`. v2 headers only (`PAYMENT-REQUIRED` / `PAYMENT-SIGNATURE` / `PAYMENT-RESPONSE`).
- **AI SDK v7:** multi-step tool loops are **off by default** (a single step) → set `stopWhen: stepCountIs(n)`. Use the documented `timeout` config.
- **wagmi v3:** the template uses `useConnection` / `useConnectors` (not `useAccount`); ignore older tutorials. `JSON.stringify` throws on `bigint` → use a replacer/reviver when posting the signed intent.
- **TypeSafe:** pin the model to `jev-1.13.0` (not `jev-latest`) so calibration stays valid.
- **Hono:** multi-client SSE broadcast is not built in → use the small `Set`-based hub from `ref-typesafe-hono.md`.
- **Intercepta:** no separate quickstart page; schemas unchanged; the `INTERCEPTA_API_KEY` was still empty at the time of the docs pass.

## Verified facts to rely on (do not re-research)
- `@x402/*` **2.27.0**; facilitator `https://x402.org/facilitator`; network `eip155:84532`; USDC `0x036CbD53842c5426634e7929541eC2318f3dCF7e` (6 decimals). Payer needs no ETH.
- Decoupled signing: agent `decodePaymentRequiredHeader` → firewall `x402Client.fromConfig({ schemes, spendControls })` + `onBeforePaymentCreation` hook (`{ abort: true, reason }`) → `createPaymentPayload` + `encodePaymentSignatureHeader` → agent retries with header `PAYMENT-SIGNATURE`.
- SDK default cap is **$1/payment** → set `spendControls: { maxAmountPerPayment: "$25" }` (or the intent budget).
- Idempotency: `payment-identifier` from **`@x402/extensions@2.27.0`** (retry → cached, no second settlement; same id + different payload → 409).
- World ID for Agents: `POST https://sandbox.auth.world.org/api/v1/device_authorization` (Basic auth, `scope=openid`, `prompt=login`) → poll `POST /api/v1/token` (`grant_type=urn:ietf:params:oauth:grant-type:device_code`) → ID token (`acr` orb-v3, `amr` pop, `auth_time`). Validate with `jose` + JWKS; check `iss`, `aud`, `exp`, `auth_time` freshness. Errors: `authorization_pending`, `slow_down`, `access_denied`, `expired_token`.
- Jev (`@typesafe-ai/sdk@0.6.0`, `jev-1.13.0`): key case #9 → `matches_intent 0.03`, `refuse`; 0/14 attacks missed; 4 legit cases escalate to `ask_human`; p50 301 ms.

## Phase 2 — From pipeline to product (Sat Sep 26)

**Goal (user, 10:00 JST Sat):** turn the working pipeline into a user-friendly product where the agent is autonomous. A user lands on the site, connects their wallet, creates a mandate for their agent, hands the agent a credential (API key / MCP config), and the agent then pays on its own through the firewall while the user watches the dashboard and approves doubts with World ID.

**Target user journey:** landing → connect wallet (login) → create mandate (task, budget, categories, expiry, human-approval threshold) → sign it → receive the agent credential + MCP snippet → agent runs autonomously → live dashboard (decisions, reasons, approvals, pause/revoke) → on-chain proof.

**Decisions already made:** single Astro + Tailwind site (`apps/site`: landing, app, dashboard) replacing `apps/web` (Next) and the firewall's plain dashboard; agent credential per mandate; MCP server so any agent can plug in; smart-account (non-custodial) funding is future work, stated honestly. **Open:** final product name and brand (gates all visual work; P0).
